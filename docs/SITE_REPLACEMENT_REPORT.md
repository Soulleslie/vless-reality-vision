# 已有节点随机网页更换：审查与测试

版本 v2.3.1，分支 `feat/replace-existing-self-domain-page`，基础 `main@1c3a57d`。所有实现仍内嵌在现有 `install.sh`，没有部署生产 VPS。

## 行为与兼容

- 新增命名命令 `vless-reality website-random` 和交互菜单 **27**。原 1–26 操作及命名/历史数字命令语义保留，菜单连续 1–27；原数字 CLI 27 仍为旧 `security-apply`，自动化应使用命名命令。
- 第 **24** 项的名称明确为「更新 Nginx 安全配置（原安全模板）」，功能仍是安全配置更新，不换网页。
- 只适用已由本项目安装的自有域名模式。旧固定网页可迁移；已有随机网页从另外五种布局中重新选择，不需保存额外模板字段或种子。日常访问、更新脚本或核心、续期、重启和域名切换不主动换页。
- UUID、REALITY 密钥/Short ID、SNI/Address、端口、TFO、Encryption、名称、节点链接、Nginx 配置和证书保持；不重启、reload 或停用任何服务，不修改外部验证/NAT 状态。

## 发布、回滚与清理

1. 共用现有目录操作锁并在锁内读取最新安装记录。校验模式、配置、目录与 SHA-256 归属、共享引用及原网站的本机 HTTPS/H2/200/正文。
2. 私有 `work/site-backup.*` 中备份旧 HTML 和原归属清单。本地一次 Python 标准库进程生成新网页，旧页面只用于读取布局类别，不带入节点配置或凭据。
3. 使用既有网站 `.well-known/acme-challenge/.page.*` 暂存公开 HTML，逐级验证路径不是符号链接、属于 root、不可由组/其他用户写入，且与首页在同一文件系统。初始文件为 600，发布为 644，使用 rename 原子替换，不让浏览器读取截断的首页。无私密数据放入网站暂存。
4. 沿用原归属记录，再次实际读取本机 Nginx HTTPS，要求 h2/200、有效证书域名和正文一致。成功清理备份、响应和发布暂存后显示成功。
5. 生成、发布、归属记录或新页面验证失败，以及可捕捉的 HUP/INT/TERM，恢复旧网页和原清单。恢复失败不删除唯一备份，明确报告位置。SIGKILL/掉电无法运行 shell 回滚，不宣称这类中断已自动恢复；保留的私有备份供修复，卸载仍先校验归属。

所有新增暂存/备份位于原卸载范围，不增加清理白名单例外。实际卸载覆盖已换网页、隐藏发布半成品、私有备份和响应文件；不删除修改过的网页、未知数据、其他服务共享资源、系统软件包或 journal。修复 `self_track` 写入/rename 失败时 receipt 临时文件未立即清理的问题，所有原管理路径继续回归。

## 速度

无公网 IP/DNS 查询、第三方测速、外部渲染接口、新依赖、证书申请/续期 dry-run 或服务重启。更换只做本地生成、文件校验与前后两次本机 HTTPS 读取；配置语法检查同样是本地执行。后续请求仍直接读取约 4–5 KB 静态文件。

v2.2.2 的 apt 成功短期复用、双 DNS 解析器并发和最多 16 个 SNI 持续任务均未调整，原性能/兼容用例继续执行。真实本机更换计时在协议测试日志中输出，不代表其他 VPS 性能或整次安装速度。

本次两代 Debian、四种 Encryption 配置共 8 次完整更换测得 **170–281 ms**（包括锁、配置/归属检查、备份、生成、两次本机 HTTPS 和清理），仅代表这次隔离开发环境。首装网页 14 个本地样本生成中位数约 44–46 ms；不会给日常网页请求增加生成开销。

## 使用

按 README 的「已有节点如何更新」安全更新管理脚本，再执行：

```bash
vless-reality website-random
```

或打开 `vless-reality` 菜单选择 **27**。成功后刷新浏览器，节点无需重新导入。若网页曾手动修改或被其他服务引用，命令会保护原文件并说明原因，不需要卸载节点来换页。
